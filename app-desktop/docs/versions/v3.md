# v3 — Monitor UI/UX Redesign

## Objective

Redesign the Monitor's visual layer so every screen communicates its content clearly at a glance. The structure is already sound; v3 fixes the UI problems that make it feel unfinished: anonymous navigation, poor status differentiation, underpowered empty states, and raw data exposed in the UI.

## Done criteria

A user opening the Monitor for the first time can navigate Setup, Deliverables, and Board without confusion. Status, progress, and focus are immediately readable without consulting documentation.

## Included in this version

- Header/nav redesign — identity, active tab treatment, project context (EPIC-11)
- Setup redesign — document cards with rich status, integrated legend, next-focus highlight (EPIC-11)
- Deliverables redesign — version progress, sprint chips with status color, epic progress bars (EPIC-11)
- Board redesign — designed empty states, unified filters, card hierarchy, system icons (EPIC-11)
- Story Detail redesign — no raw YAML, two-column meta/content layout (EPIC-11)

## Explicitly out

- New features or data not already present in the Monitor
- Tauri/native packaging (moved to future version)
- Authoring wizards (v4)
- Export / GitHub bridge (v5)
