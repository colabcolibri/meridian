# v3 — Native Desktop Monitor

## Objective

Ship the v1 monitor as a **native desktop app** (Tauri) with bundled Meridian scripts and persistent folder access — production-ready for managers who do not run `pnpm dev`.

## Done criteria

User installs the desktop app, opens `docs/`, runs validation and views all tabs; `pnpm build` artifact does not require Vite dev API for Python validation.

## Included in this version

- Tauri shell around `app-desktop/` (EPIC-07).
- Native invoke of `validate_meridian.py` and `generate_board.py`.
- Persist last opened `docs/` path (OS storage).
- File watcher refresh when `us/` or `board.json` changes on disk (after v2 extension writes).

## Explicitly out

- Extension feature parity (stays in VS Code).
- Export / GitHub (v5).
- Authoring wizards (v4).
