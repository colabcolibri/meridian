# v4 — VS Code bridge

## Objective

Editor extension for real Markdown writes in the workspace folder, board generation, and Meridian operation without relying only on the browser. Deferred from the old v2 label so v2 could deliver monitor kanban polish first.

## Done criteria

VSCode user creates a US referencing existing epic and version, saves to disk, and board.json regenerates without a fragile manual step.

## Included in this version

- VS Code extension in `app-visual-studio/` (EPIC-05).
- Script `generate_board.py` callable from extension, CI, and agents.
- Commands: sync board, validate project, new user story.
- Writes to `docs/us/`; templates for `docs/epics/` and `docs/versions/`.
- Kit docs and CI for the extension.

## Explicitly out

- Web monitor as markdown author (remains reader).
- Drag-and-drop kanban status changes.
- Backend, auth, or multi-user.
- Tauri / Python validation without dev server (v7).
- Full epic/version wizards (templates only; guided workflows → v5).
