# v2 — Kanban and board polish

## Objective

Strengthen **Deliverables** and **Board** in the browser monitor (EPIC-04): derived kanban from `docs/us/`, visual doc-status on cards, columns that hide when empty, lightweight index on folder open, and protocol alignment for implementation records. This is the natural second release after v1 folder reading — not the VS Code extension.

## Done criteria

Opening `docs/` in the monitor loads quickly; the Board shows only meaningful columns; each card signals documentation health; validator flags ✅ US without a real `## Record`; optional warning when `board.json` is stale vs parsed US.

## Included in this version

- Board documentation UX — validate implementation record, Doc badge, lean columns (EPIC-03/04 — US-0073–0075, sprint v2-S5).
- Lightweight folder index — frontmatter-only open, bodies on demand (US-0076, sprint v2-S6).
- Monitor stale `board.json` warning (US-0051, Should — sprint v2-S4).
