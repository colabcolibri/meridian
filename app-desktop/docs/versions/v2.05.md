# v2.05 — Codex adapter and extension onboarding

## Objective

US-0100 delivered kit install and surgical sync for Cursor and Claude only. Codex users had no adapter path, and the VS Code extension help was split between Command Help and Agents Help without Start Here or Usage Guide panels — managers could not tell whether to use extension commands or chat slash workflows.

This release adds **Codex IDE adapters** (`.agents/skills/workflow-*`, `.codex/agents/`, `AGENTS.md`) via the same sync/install scripts, and **reorganizes extension onboarding**: How to Use tab, Start Here and Usage Guide editor tabs, grouped Commands sidebar, and kit doc updates. Extension ships as **meridian-vscode 1.1.13**.

## Done criteria

After Install Harness, `sync_cursor_kit.sh` creates Codex adapters; workflows are invokable as `workflow-*` skills without colliding with kit skills. In the IDE, a new user can follow Guides 1→4 in the sidebar, understand that they type `/create-us` (not @agents), and install the VSIX with bundled kit containing the updated references.
