# v2.03 — Multi-product repos

## Objective

Managers running **more than one Meridian product** in the same Git repository need a shared contract: where each `docs/` lives (any path), how to declare products (manifest), how tools discover them (folder name exactly `docs` + fingerprint), and how the IDE picks the **active** tree for board, validate, and sync.

This release ships kit documentation, `.meridian/projects.json` template, extension resolver + picker, and updated `/status` / `init-project` guidance. It does not merge boards or add desktop multi-home UI.

## Done criteria

With two Meridian `docs/` folders in one repo (e.g. root `docs/` and `apps/pkg/docs/`), the extension lists both projects, remembers the active choice, validates the package folder that owns the active `docs/`, and ignores `docs-extra`. Kit `projects-manifest-template.md` and `usage-guide.md` describe the same rules agents follow.
