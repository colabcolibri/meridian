# v1 — Folder Monitor MVP

## Objective

Manage the project **through the same files** that agents edit (`docs/`, `docs/us/`, `board.json`).

## Done criteria

User opens the project's `docs/` folder (e.g. `app-desktop/docs/`); the 3 tabs reflect the `.md` files without mock or `data.ts` as source.

## Included in this version

- File System Access to choose the `docs/` folder.
- Frontmatter parser for phase docs, epics, versions, and `docs/us/`.
- Validations aligned with the protocol and `validate_meridian.py`.
- **Get Started** guide and monitor UX (EPIC-06).

## Explicitly out

- US/docs editing via the browser.
- Tasks/Bug/Spike as separate artifacts (remain inside the US or in chat).
