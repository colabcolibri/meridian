# US-005 — Criar skills iniciais em .agent

**Como** Manager do Processo,
**quero** ter skills auxiliares dentro de `.agent/skills`,
**para que** agentes de IA executem tarefas recorrentes do Meridian com mais consistência.

## Aceite

- Pasta `.agent/skills/` criada.
- Skills usam pacote com `SKILL.md` e frontmatter.
- Skills iniciais criadas para iniciar projeto, revisar segurança, criar US, gerar board JSON e atualizar decisões.
- `.agent/MERIDIAN.md` menciona `.agent/skills/` como camada auxiliar operacional.
- Segurança no `meridian.md` foi aprofundada para cobrir segredos, agentes, dados, OWASP, dependências e logs.

## Implementação técnica

### Frontend

- Sem alteração funcional além de manter a home alinhada ao conceito.

## Testes

- `pnpm format:check`
- `pnpm lint`
- `pnpm build`

## Fora de escopo desta story

- Transformar skills em pacote instalável.
- Criar UI de gerenciamento de skills.

## Notas

- Skills são extra-app e servem agentes de IA diretamente.
