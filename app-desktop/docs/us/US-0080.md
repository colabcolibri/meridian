# US-0080 — Board screen redesign

**As** Process Manager,
**I want** the Board to look intentional whether columns are empty or full,
**so that** I can read card status and filter stories without the interface feeling broken or unfinished.

## Intent

### Acceptance

- [x] Empty columns show a designed empty state with a brief label explaining the meaning of that status (e.g. "No stories pending — all work is accounted for"), not just "No stories in this column."
- [x] The two filter controls (Filter versions and Filter by epic) are visually unified into a single filter bar or panel — they do not appear as two disconnected white cards stacked above the board.
- [x] Kanban cards have a clear visual hierarchy: US ID and status badge are secondary; title is the primary element; epic label and description are tertiary.
- [x] Column header status icons are from the UI icon set (not native emoji) and are consistent in size and style with other icons in the app.
- [x] The `ⓘ` tooltip on each column header has a visible label or accessible tooltip text explaining the column's meaning.

### Why

The Board today has a structural problem: in the most common state (v1 complete, all stories done), four of five columns display "No stories in this column" with no explanation. This looks like a loading error, not a healthy board. A first-time user cannot tell if the app is broken or if the board is correctly showing an empty state. Additionally, the two filter blocks above the board feel like separate UI components rather than a unified control surface, and card internals give equal weight to ID, title, and description — there is no reading hierarchy. This story addresses all three: empty states get meaning, filters get unity, cards get hierarchy.

### Where

Fourth story in v3 / EPIC-11 — depends on US-0077. The Board reads from `docs/kanban/board.json` (already generated). This story touches the Board tab, column components, card components, and the filter bar. No data layer changes. Unblocks US-0081 (Story Detail redesign, triggered from card click).
