# US-0058 — Persist last opened docs folder

**As** Process Manager,
**I want** the app to remember my docs folder,
**so that** daily orienting does not require re-picking the folder.

## Intent

### Acceptance

- [ ] Last path stored in OS-safe app storage.
- [ ] On launch auto-reopen when path exists; graceful fallback when missing.
- [ ] Clear-folder action resets persistence.
