# US-0012 — Deliverables tab reads docs/epics/

**As** Process Manager,
**I want** to see the epics defined in `docs/epics/`,
**so that** I align product priorities with the user story backlog.

## Acceptance

- [x] Cards generated from parsed `docs/epics/EPIC-XX.md` (not a fixed array in `data.ts`).
- [x] Each epic shows description, versions, active/paused/complete status, and US count (`docs/us/`).
- [x] Paused epics (e.g. EPIC-05) appear in a separate section.
- [x] Completed epics (e.g. EPIC-01) in a **Completed** section.
- [x] Changing a file in `docs/epics/` and reloading folder updates the tab.
