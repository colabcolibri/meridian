# US-0074 — Documentation badge on kanban cards

**As** Process Manager,
**I want** to see at a glance whether a US has its implementation documented,
**so that** I do not open every story file to audit closure quality.

## Intent

### Acceptance

- [x] `KanbanStoryCard` shows **Doc** badge when implementation status is `documented`.
- [x] Shows **Sem doc** badge (amber) when status is `✅` or `🔶` and implementation is `missing` or `placeholder`.
- [x] No documentation badge on `❌` cards (or neutral tooltip only — not required).
- [x] Badge has accessible label/tooltip explaining “Implementação técnica registrada no arquivo”.
- [x] Card border warning aligns with existing `storyIssues` when protocol error exists (no duplicate logic).
- [x] Responsive layout — badge does not overflow card on mobile.

### Why

This story delivered **Documentation badge on kanban cards**: `KanbanStoryCard` shows **Doc** badge when implementation status is `documented`.. It existed so that I do not open every story file to audit closure quality. The record of what shipped lives under `## Technical implementation`.

### Where

Release **v2** (`EPIC-04` in frontmatter — not duplicated here). Depends on US-0073 and US-0013 — read those US files for what must already work. Stops before: Hiding kanban columns (US-0075).
