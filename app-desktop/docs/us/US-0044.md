# US-0044 — generate_board.py script in kit

**As** Process Manager,
**I want** a deterministic script to regenerate board.json,
**so that** the extension, CI, and agents share one implementation instead of fragile manual JSON edits.

## Acceptance

- [ ] New script `.agent/scripts/generate_board.py` accepts project root (folder containing `docs/`).
- [ ] Reads all `docs/us/US-*.md`, extracts frontmatter fields per `board-schema.md`.
- [ ] Validates epic/version refs; exits non-zero with clear errors on invalid US.
