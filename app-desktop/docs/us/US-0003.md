# US-0003 — Configure Git and local quality

**As** Process Manager,
**I want** the project to have Git, protected sensitive files, and local checks,
**so that** AI agents and people work with consistency from the foundation.

## Acceptance

- Git repository initialized.
- `.gitignore` protects `.env`, builds, dependencies, logs, and incorrect lockfiles.
- `.env.example` exists as configuration contract.
- Prettier configured.
- Husky configured.
- lint-staged configured in pre-commit.
- `pnpm format:check`, `pnpm lint`, and `pnpm build` pass.

## Technical implementation

### Frontend

- Add quality scripts to `package.json`.
- Add `.editorconfig`, `.prettierrc.json`, `.prettierignore`, and VS Code settings.
- Configure `.husky/pre-commit` hook.
