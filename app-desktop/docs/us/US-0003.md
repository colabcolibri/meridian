# US-0003 — Configurar Git e qualidade local

**Como** Manager do Processo,
**quero** que o projeto tenha Git, arquivos sensíveis protegidos e checks locais,
**para que** agentes de IA e pessoas trabalhem com consistência desde a fundação.

## Aceite

- Repositório Git inicializado.
- `.gitignore` protege `.env`, builds, dependências, logs e lockfiles incorretos.
- `.env.example` existe como contrato de configuração.
- Prettier configurado.
- Husky configurado.
- lint-staged configurado no pre-commit.
- `pnpm format:check`, `pnpm lint` e `pnpm build` passam.

## Implementação técnica

### Frontend

- Adicionar scripts de qualidade no `package.json`.
- Adicionar `.editorconfig`, `.prettierrc.json`, `.prettierignore` e settings de VS Code.
- Configurar hook `.husky/pre-commit`.

## Testes

> Na **criação**: preencher **Planejado**. Ao **fechar** (`complete-user-story`): marcar `[x]` e registrar em **Executado**.

### Planejado

- [x] **lint** — `pnpm format:check`
- [x] **lint** — `pnpm lint`
- [x] **build** — `pnpm build`

### Executado

- `pnpm format:check`, `pnpm lint` e `pnpm build` passaram em `app-desktop/`.
