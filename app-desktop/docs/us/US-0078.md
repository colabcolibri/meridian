# US-0078 — Setup screen redesign

**As** Process Manager,
**I want** the Setup screen to show document health and what to work on next at a glance,
**so that** I can open the app and immediately know the project's documentation maturity without scanning text.

## Intent

### Acceptance

- [x] Document cards within each phase group use distinct visual states for Ready, In progress, Not started, and Attention — differentiable by color or icon without reading a legend.
- [x] The status legend is integrated into the card design (tooltip or inline) rather than appearing as a freestanding text block in the middle of the page.
- [x] The progress summary ("8 of 10 documents ready") is the dominant element of the section — not a large isolated number — and includes a progress bar with clear percentage.
- [x] The "Next focus" recommendation is visually prominent and positioned so it reads as an actionable callout, not a sidebar decoration.
- [x] The "Advanced tools" disclosure is visually anchored — clearly secondary but not abandoned at the top of the page.

### Why

The current Setup screen has three problems in hierarchy. First, a giant isolated number (`8`) dominates but carries no actionable meaning. Second, the status legend floats as plain text between sections — the most important key to reading the screen is the least visible element. Third, document cards are visually identical regardless of status; Ready and Not started look the same until you inspect the icon closely. This story fixes all three: cards communicate status independently, the legend disappears into context, and the progress summary is informative without being theatrical.

### Where

Second story in v3 / EPIC-11 — depends on US-0077 (header baseline). The Setup screen is self-contained; this story touches only the Setup tab component and its document card sub-components. Unblocks nothing directly but establishes the card pattern that Deliverables may reuse.

## Plan

### Approach

- `PhaseStepCard` shows `setupStepMeta[state].shortLabel` on every state including `complete`.
- `SetupStateLegend` moved inside `SetupProgressHeader` card.
- Progress bar + percentage anchor the summary; raw count demoted to caption.
- "Next focus" callout uses `border-2 border-meridian` prominence.
