# US-0042 — Detect Meridian workspace in extension

**As** Future VSCode User,
**I want** the extension to recognize a Meridian project in my workspace,
**so that** commands only run when the folder structure is valid.

## Acceptance

- [ ] On activation, extension checks for `.agent/MERIDIAN.md` at workspace root (or nested project root per architecture).
- [ ] Resolves `docs/` path relative to workspace; warns if missing.
- [ ] Status bar item shows "Meridian" with tooltip: kit detected, docs path, US count (read-only).
- [ ] Commands disabled or show clear message when workspace is not Meridian.
- [ ] Works when workspace root is `meridian/` monorepo or a client project with only `.agent/` + `docs/`.
