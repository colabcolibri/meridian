# US-0042 — Detect Meridian workspace in extension

**As** Future VSCode User,
**I want** the extension to recognize a Meridian project in my workspace,
**so that** commands only run when the folder structure is valid.

## Intent

### Acceptance

- [x] On activation, extension checks for `.agent/MERIDIAN.md` at workspace root (or nested project root per architecture).
- [x] Resolves `docs/` path relative to workspace; warns if missing.
- [x] Status bar item shows "Meridian" with tooltip: kit detected, docs path, US count (read-only).
- [x] Commands disabled or show clear message when workspace is not Meridian.
- [x] Works when workspace root is `meridian/` monorepo or a client project with only `.agent/` + `docs/`.

### Why

This story adds **Detect Meridian workspace in extension** — the extension to recognize a Meridian project in my workspace. When done, commands only run when the folder structure is valid. It is intentionally one slice; it does not deliver the whole epic alone.
