# US-0075 — Lean kanban columns — hide empty and collapse frozen

**As** Process Manager,
**I want** a board that hides empty columns and tucks away frozen work,
**so that** I focus on active delivery without scrolling past unused lanes.

## Acceptance

- [x] Columns ❌, 🔶, 🧪 and ✅ always remain visible (including when empty).
- [x] Column 🧊 hidden by default; not rendered unless toggled on.
- [x] When no US have status 🧊, no frozen column and no frozen control visible.
- [x] When frozen US exist: show compact control (e.g. “🧊 N congeladas — mostrar”) below the board or in filter panel; toggling reveals frozen column or filtered view.
- [x] Default state: frozen hidden even when count > 0.
- [x] Grid uses 4 columns by default; 5 when frozen lane is expanded.
- [x] Column order preserved: ❌ → 🔶 → 🧪 → ✅ → 🧊 (when shown).
