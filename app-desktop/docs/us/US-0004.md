# US-0004 — Separate universal protocol and desktop app

**As** Process Manager,
**I want** to separate the Meridian protocol from the desktop app,
**so that** any project can use `meridian.md` without depending on the management system.

## Acceptance

- `meridian.md` remains at the root as a universal protocol and instruction for AI agents.
- Vite app, configs, dependencies, and internal documentation stay in `app-desktop/`.
- `.gitignore` protects generated and sensitive files in subfolders.
- Husky runs checks inside `app-desktop/`.
- App home communicates that it monitors a Meridian folder.
