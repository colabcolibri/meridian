# US-002 — Ver documentos de fase e status

**Como** Manager do Processo,
**quero** ver os documentos de fase e seus status,
**para que** eu saiba o que está pronto, bloqueado ou pendente antes de avançar.

## Aceite

- App lista os documentos `00` a `11`.
- Cada documento mostra status atual.
- Dependências principais ficam visíveis.
- Documentos bloqueados são diferenciados visualmente.
- O board canônico permanece em `docs/kanban/board.json`.

## Implementação técnica

### Frontend

- Criar dados iniciais do fluxo Meridian em TypeScript.
- Criar painel de documentos.
- Criar badges de status.
- Criar cálculo básico de bloqueio por dependência.

## Testes

- `pnpm build` passou.
- Listagem e estados visuais implementados na tela inicial.
