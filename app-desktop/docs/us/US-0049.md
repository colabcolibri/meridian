# US-0049 — Auto-regenerate board after US create or save

**As** Future VSCode User,
**I want** board.json to update when I save a user story,
**so that** the monitor and validator always see current status.

## Intent

### Acceptance

- [ ] After US-0047 creates a file, extension runs Sync Board automatically (or prompts once with "Always sync").
- [ ] On save of any `docs/us/US-*.md`, triggers board regen when setting `meridian.autoSyncBoard` is true (default true).
- [ ] Debounce saves (e.g. 500ms) to avoid race on rapid edits.
- [ ] On regen failure, show error; US file remains saved.
- [ ] v2 done criteria satisfied: create US + save → board.json updated without manual JSON edit.

### Why

This story adds **Auto-regenerate board after US create or save** — board.json to update when I save a user story. When done, the monitor and validator always see current status. It is intentionally one slice; it does not deliver the whole epic alone.
