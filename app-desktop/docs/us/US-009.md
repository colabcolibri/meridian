# US-009 — Abrir pasta Meridian no app

**Como** Manager do Processo,
**quero** abrir a pasta `docs/` do meu projeto Meridian no app desktop,
**para que** o monitor mostre o mesmo conteúdo que edito com agentes no Cursor.

## Aceite

- [x] Botão **Abrir pasta** habilitado na shell do monitor.
- [x] Pasta válida é a pasta `docs/` do projeto (`00_scope.md` na raiz e subpasta `us/`).
- [x] Pasta inválida exibe mensagem clara sem quebrar o app.
- [x] Pasta escolhida é reaberta na mesma sessão do browser (File System Access API + IndexedDB).
- [x] Dogfooding: abrir `app-desktop/docs/` como pasta monitorada funciona.
