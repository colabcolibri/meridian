# US-0018 — Onboarding para abrir pasta docs

**Como** Manager do Processo,
**quero** ser guiado na primeira abertura do app,
**para que** eu saiba exatamente qual pasta escolher sem ler README.

## Aceite

- [x] Tela inicial sem pasta: título orientado a benefício (não jargão de API).
- [x] Três passos numerados (o que é docs, o que acontece ao abrir, navegador suportado).
- [x] Um botão primário destacado "Abrir pasta do projeto".
- [x] Evidência: `WelcomeScreen.tsx`, `pnpm build`.

## Implementação técnica

### Frontend

- `WelcomeScreen.tsx` substitui `OpenFolderPrompt` quando não há pasta.

## Testes

- Manual: abrir app sem pasta → ver onboarding → abrir `app-desktop/docs/`.

## Fora de escopo desta story

- Tour após pasta aberta (v1-S2+).

## Notas

- Depende de US-0009 (File System Access).
