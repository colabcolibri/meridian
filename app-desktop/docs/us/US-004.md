# US-004 — Separar protocolo universal e app desktop

**Como** Manager do Processo,
**quero** separar o protocolo Meridian do app desktop,
**para que** qualquer projeto possa usar `meridian.md` sem depender do sistema de gestão.

## Aceite

- `meridian.md` permanece na raiz como protocolo universal e instrução para agentes de IA.
- App Vite, configs, dependências e documentação interna ficam em `app-desktop/`.
- `.gitignore` protege arquivos gerados e sensíveis em subpastas.
- Husky roda checks dentro de `app-desktop/`.
- Home do app comunica que ele monitora uma pasta Meridian.

## Implementação técnica

### Frontend

- Mover estrutura Vite para `app-desktop/`.
- Ajustar tela inicial para "Abrir pasta" e monitoramento de projeto.
- Atualizar dados simulados do dashboard.

## Testes

- `pnpm format:check`
- `pnpm lint`
- `pnpm build`
- `sh .husky/pre-commit`

## Fora de escopo desta story

- Implementar abertura real de pasta.
- Criar `app-visual-studio/`.

## Notas

- O sistema de gestão é uma camada opcional sobre a pasta do projeto.
