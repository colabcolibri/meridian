### Why

The manager added a complete Scrum reference (`scrum-guide-complete`) but Meridian agents must not treat it as operational protocol — that would bloat context and invite story points, task folders, and PO agents. Without a single map, each session would reinterpret Scrum differently. After this US, humans learn from the optional textbook; agents and daily workflows use `scrum-meridian-map.md` and the in-app section, keeping files as source of truth.
