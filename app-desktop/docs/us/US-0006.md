# US-0006 — Organizar camada operacional .agent

**Como** Manager do Processo,
**quero** que a camada operacional de agentes use uma estrutura formal `.agent`,
**para que** agents, skills, workflows, rules e scripts fiquem organizados e reutilizáveis.

## Aceite

- `.agent/ARCHITECTURE.md` documenta a arquitetura da camada de agentes.
- `.agent/agents/` contém agentes Meridian iniciais.
- `.agent/skills/` contém skills como pacotes com `SKILL.md`.
- `.agent/workflows/` contém workflows operacionais.
- `.agent/rules/` contém regras globais.
- `.agent/scripts/` contém script inicial de validação.
- `meridian.md` documenta `.agent/` como estrutura oficial.

## Implementação técnica

### Frontend

- Sem mudança funcional obrigatória.
- Home continua mencionando skills como parte do kit para agentes.

## Testes

- `pnpm format:check`
- `pnpm lint`
- `pnpm build`
- `python3 .agent/scripts/validate_meridian.py app-desktop`

## Fora de escopo desta story

- Criar CLI de instalação da camada `.agent`.
- Criar UI para gerenciar agents/workflows.

## Notas

- A referência estrutural veio do padrão observado no `antigravity-kit`, adaptado para Meridian.
