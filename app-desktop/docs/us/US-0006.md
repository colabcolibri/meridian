# US-0006 — Organize .agent operational layer

**As** Process Manager,
**I want** the agent operational layer to use a formal `.agent` structure,
**so that** agents, skills, workflows, rules, and scripts are organized and reusable.

## Acceptance

- `.agent/ARCHITECTURE.md` documents the architecture of the agent layer.
- `.agent/agents/` contains initial Meridian agents.
- `.agent/skills/` contains skills as packages with `SKILL.md`.
- `.agent/workflows/` contains operational workflows.
- `.agent/rules/` contains global rules.
- `.agent/scripts/` contains the initial validation script.
- `meridian.md` documents `.agent/` as the official structure.
