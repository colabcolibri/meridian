# US-007 — Alinhar kit `.agent` ao padrão Antigravity

**Como** Manager do Processo,
**quero** que o kit Meridian siga a mesma profundidade operacional do Antigravity (rules, routing, references, workflows),
**para que** agentes executem governança documental com progressive disclosure e roteamento explícito.

## Aceite

- [x] `README.md` na raiz do repositório do kit (convenção Git).
- [x] `.agent/rules/MERIDIAN.md` com `trigger: always_on` e prioridade P0/P1/P2.
- [x] Skill `meridian-routing` e guia `.agent/skills/doc.md`.
- [x] Skills com `allowed-tools`, tabela selective reading e `references/`.
- [x] Agents expandidos com fases, gates, proibições e formato de saída.
- [x] Workflows com `$ARGUMENTS`, regras críticas e bloco CONTEXT.
- [x] `.agent/ARCHITECTURE.md` documenta diferenças vs Antigravity.
- [x] `meridian.md` e `app-desktop/docs` referenciam a estrutura nova.
