# US-0099 — Command help reference tab in VS Code extension

**As** Process Manager,
**I want** an in-IDE help page that explains each Meridian command,
**so that** I do not need to remember what Validate, Sync Board, or Workspace status do before using them.

## Intent

### Acceptance

- [x] **Meridian: Open Command Help** opens an editor tab with grouped reference (Views, Governance, Planned v5).
- [x] Each command documents: palette title, summary, behavior bullets, and Output channel when applicable.
- [x] Covers **Open Board / Versions / Sprints / Epics**, **Validate Project**, **Sync Board**, **Workspace status**, **New User Story** (stub), and **Open Deliverables** alias.
- [x] **Commands** sidebar lists **Command help** as first item; same entry under **View → Meridian**.
- [x] Single catalog source (`command-catalog.ts`) drives sidebar descriptions and help HTML.
- [x] `pnpm test` includes `help-webview.test.ts`.

### Why

After v4-S7 the extension exposes many commands across sidebar, menu, and palette. Managers asked for a help surface — especially for Validate (kit script), Sync Board (derived JSON vs live board read), and Workspace status (monorepo docs path). A static reference tab avoids hunting README or chat.

### Where

v4-S8 polish after US-0098. Last read-surface slice of EPIC-05 before v5 authoring wizards.
