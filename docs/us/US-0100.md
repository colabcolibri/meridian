# US-0100 — Distributable meridian-kit install and surgical IDE sync

**As** Process Manager,
**I want** to install and upgrade the Meridian kit in any repository from a standalone package,
**so that** I get agents, skills, and IDE slash commands without cloning the full monorepo and without losing my own `.cursor/` or `.claude/` files.

## Intent

### Acceptance

- [x] **`package-kit.sh`** builds `dist/meridian-kit-VERSION.tar.gz` containing `.agent/`, root `install.sh`, `README`, `LICENSE`, and `VERSION` — no `app-desktop/` or extension sources.
- [x] **`install-meridian-kit.sh`** (and tarball `install.sh`) copies `.agent/` into the target project; **`--force`** uses `rsync --delete` to replace the kit tree on upgrade; default install refuses to overwrite an existing `.agent/` without `--force`.
- [x] After install, **`sync_cursor_kit.sh`** runs (unless `--no-sync`) and creates/updates Meridian symlinks under `.cursor/` and `.claude/` for agents, skills, workflows, commands, rules, and template registry paths documented in `IDE_ADAPTERS.md`.
- [x] **Surgical sync:** script never deletes `.cursor/` or `.claude/` directories wholesale; it only replaces symlinks whose targets resolve under `.agent/`; **orphan** Meridian symlinks (kit entity removed) are removed; **real files** and symlinks pointing outside `.agent/` are left untouched.
- [x] **`KIT_README.md`** documents build, install, upgrade, `--dry-run`, IDE matrix (Cursor, Claude, Antigravity), and the non-destructive adapter policy; `IDE_ADAPTERS.md` links to it.
- [x] Manual smoke: fresh install + re-install with pre-existing custom rule file survives; `--no-sync` installs `.agent/` only.

### Why

US-0006 and US-0007 organized the `.agent/` layer but explicitly stopped before an installer for external projects. Today managers either clone the monorepo or copy folders manually; re-upgrading the kit risks stale workflows or, worse, scripts that wipe entire `.cursor/` trees. This story delivers the deferred installer slice: a distributable tarball and install path that treats `.agent/` as replaceable while IDE adapters are managed surgically.

### Where

Release **v2.02** (`v2.02-S1`), first slice of **EPIC-12** (kit distribution — new epic; EPIC-01 stays closed at v0). Depends on **US-0007** (operational kit depth — agents, routing, workflows). Unblocks dogfooding Meridian in repos that are not the monorepo and sets the contract before any future `npx` wrapper.

## Plan

### Approach

- **`package-kit.sh`** — stage `.agent/`, `KIT_README.md` as `README.md`, embed `install.sh` wrapper setting `MERIDIAN_KIT_SRC`.
- **`install-meridian-kit.sh`** — rsync copy, optional `--force`, adapter flags (`--no-sync`, `--cursor-only`, `--claude-only`), gitignore helpers.
- **`sync_cursor_kit.sh`** — track expected link paths; `prune_orphans` removes Meridian symlinks not in expected set; never touch real files.
- **Docs** — IDE matrix in `KIT_README.md` and `IDE_ADAPTERS.md`: Cursor/Claude need adapters; Antigravity reads `.agent/` directly.
