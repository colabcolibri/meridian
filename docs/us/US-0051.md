# US-0051 — Monitor stale board.json warning

**As** Process Manager,
**I want** the monitor to warn when board.json is out of date,
**so that** I know to sync after editing US in the editor.

## Intent

### Acceptance

- [ ] When folder loaded, compare exported fields from `us/*.md` frontmatter vs `kanban/board.json` entries.
- [ ] If mismatch (missing id, status, tests_status, etc.): issue banner or Setup alert with "Board out of sync — run Sync Board in VS Code".
- [ ] If board.json missing but US exist: same warning.
- [ ] No write from browser; read-only detection only.
- [ ] Warning clears after user re-opens folder with synced board.
