# v7 — Native Desktop Shell

## Objective

Wrap the existing Vite monitor in Tauri (or equivalent) so the manager opens `docs/` with native file access, persists the last folder, and runs `validate_meridian.py` / `generate_board.py` without the Vite dev-server API bridge. Previously mislabeled as v3 (Tauri) while v3 delivered UI redesign (EPIC-11).

## Done criteria

Production desktop artifact opens dogfood `docs/`, runs validate and board sync locally, and persists the last folder path across sessions.

## Included in this version

- Tauri decision and scaffold (EPIC-07 — US-0054–0056).
- Native invoke validate + generate_board (US-0057).
- Persist last opened docs/ path (US-0058).
- File watcher refreshes monitor (US-0059, Should).
- Go-live closure (US-0060).

## Explicitly out

- Export / GitHub (v6).
- Multi-user cloud (v8 vision gate).
