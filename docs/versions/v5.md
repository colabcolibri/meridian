# v5 — Authoring Workflows

## Objective

Move from **file templates** (v4) to **guided workflows** in the VS Code extension — the same operations agents do via `/complete-us`, `/plan-sprint`, and `update-decisions-log`, but usable by the manager in the editor.

## Done criteria

Manager completes a US end-to-end from the extension (status ✅, Record section, board sync, validator pass) without running slash commands in chat.

## Included in this version

- Sprint wizard (EPIC-08).
- Complete User Story helper (EPIC-08).
- New decision JSON entry helper (EPIC-08).
- US status commands (done / partial / frozen) with board sync (EPIC-04 + EPIC-08).
- Extension Problems panel for validator output (Should).

## Explicitly out

- Web kanban drag-and-drop.
- GitHub / CSV export (v6).
- Tauri changes beyond compatibility fixes.
