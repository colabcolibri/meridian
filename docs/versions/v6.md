# v6 — Export and Git Context

## Objective

Deliver **derived exports** and lightweight **Git/GitHub context** so Meridian progress can be shared and correlated with repository activity — without becoming a project-management SaaS.

## Done criteria

Manager exports kanban to CSV from extension or native app; optional GitHub repo link shows last commit affecting `docs/us/` in the monitor.

## Included in this version

- CSV export of board (EPIC-09).
- Markdown sprint summary export (EPIC-09).
- Read-only GitHub repo link + commit hint (EPIC-09, Could depth).

## Explicitly out

- Issues/PR sync, webhooks, OAuth apps with write scope.
- Backend Meridian server.
- Multi-user (v7 vision).
