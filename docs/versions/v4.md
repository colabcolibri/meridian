# v4 — Meridian in the IDE

## Objective

Ship an **installable** VS Code extension (`app-visual-studio/`) — the same class of product as Markdown readers, GitLens, etc.: distributed via Marketplace (or `.vsix`), activates on Meridian workspaces, **Commands** sidebar plus **Board** and **Deliverables** editor tabs for delivery tracking.

The extension is the **primary surface** for following kanban, epics, and versions from the project's `docs/` folder. F5 / Extension Development Host is **development only**; end users **install** the extension.

**Sync board / new US commands are not the goal of v4.** Agents and `/sync-board` in Cursor already keep `docs/us/` and `board.json` aligned. The extension **displays** that truth; optional writes come later.

## Done criteria

With a Meridian workspace open and the extension installed, the manager uses **View → Meridian** or the **Commands** tree to open **Board** and **Deliverables** in editor tabs. Board shows kanban columns with version/epic filters; Deliverables shows releases with sprints and epic progress. Clicking a card or row opens the matching file under `docs/`. **Validate Project** runs `validate_meridian.py` from the kit. No browser tab is required for day-to-day tracking; v4 is **complete** when this is true on dogfood `app-desktop/docs/` and documented in `05_architecture.md`.
